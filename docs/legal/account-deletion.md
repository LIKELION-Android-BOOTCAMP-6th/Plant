# Plant 계정 삭제 안내

시행일: 2026년 11월 26일

이 페이지는 Plant 앱의 계정과 데이터를 삭제하는 방법을 안내합니다. 앱 안에서 직접 삭제할 수 있고, 앱을 설치하지 않았거나 로그인할 수 없는 경우에는 메일로 삭제를 요청할 수 있습니다.

## 1. 앱에서 직접 삭제하기

1. Plant 앱을 열고 Google 계정으로 로그인합니다.
2. 하단의 **마이페이지** 탭에서 **계정 관리**를 누릅니다.
3. **회원탈퇴**를 누르고, 첫 번째 확인 창("탈퇴 하시겠습니까?")에서 **예**, 두 번째 확인 창("정말로 탈퇴하시겠습니까?")에서 **탈퇴**를 누릅니다.
4. 본인 확인을 위해 Google 계정을 다시 선택합니다.
5. 확인이 끝나면 계정과 데이터가 바로 삭제되고 "회원탈퇴가 완료되었습니다." 안내가 표시됩니다.

삭제되는 것은 Plant의 계정과 데이터이며, Google 계정 자체는 삭제되지 않습니다.

## 2. 앱 없이 삭제 요청하기

아래 경우에는 메일로 삭제를 요청해 주세요.

- 앱을 설치하지 않았거나 이미 삭제한 경우
- 앱에 로그인할 수 없는 경우
- 가입(닉네임 설정)을 마치지 않아 앱에서 탈퇴할 수 없는 경우

요청 방법:

1. Plant에 로그인할 때 사용한 Google 계정의 이메일 주소에서 아래 문의처로 메일을 보냅니다. 본인 확인을 위해 해당 주소에서 보낸 메일만 처리합니다.
2. 메일 제목은 "Plant 계정 삭제 요청"으로 적어 주세요. 본문은 비워 두어도 됩니다.
3. 요청을 받으면 지체 없이 아래 3절과 같이 삭제하고, 처리 결과를 메일로 알려 드립니다.

로그인에 사용한 Google 계정을 잃어 해당 주소에서 메일을 보낼 수 없다면, 먼저 [Google 계정 복구](https://accounts.google.com/signin/recovery)로 계정을 되찾은 뒤 그 주소에서 요청해 주세요. 다른 주소에서 보낸 요청은 본인임을 확인할 수 없어 처리하지 않습니다. 계정을 되찾으면 1절과 같이 앱에서 직접 삭제할 수도 있습니다.

## 3. 삭제되는 데이터와 남는 데이터

앱에서 탈퇴하거나 메일로 요청하면 아래와 같이 처리합니다. 자세한 내용은 [개인정보처리방침](https://plant-82b09.web.app/privacy-policy.html) 3절을 참고해 주세요.

### 가. 바로 삭제되는 데이터

- 계정 정보(Google 계정 이메일, UID, 가입·최근 로그인 시각), 닉네임, 프로필 이미지 선택값, 가입 동의 기록, 로그인 세션 식별값
- 학습 기록, 화분 데이터, 골드·아이템, 보너스 박스 열기 결과 기록, 출석 체크 기록
- 내가 작성한 게시글(게시글에 달린 댓글 포함)과 커뮤니티 활동 내역
- 다른 이용자의 게시글에 남긴 좋아요·북마크
- 내가 만든 차단 목록
- 실시간 학습 현황

※ 다른 이용자가 나를 차단한 기록(그 이용자의 차단 목록에 있는 내 UID와, 차단할 때 게시글·댓글에 표시된 내 닉네임·프로필 이미지 선택값)은 탈퇴해도 지워지지 않고, 그 이용자가 차단을 해제하거나 탈퇴할 때까지 남습니다. 이 기록은 그 이용자에게만 표시됩니다.

### 나. 개인을 알아볼 수 없는 형태로 남는 데이터

| 데이터 | 처리 방식 | 남기는 이유 |
|--------|----------|------------|
| 다른 이용자의 게시글에 남긴 댓글 | 내용은 "- 삭제된 댓글입니다. -"로, 작성자는 "(알 수 없음)"으로 바꾸고 댓글 자리만 남김 | 다른 이용자의 대화 흐름 유지 |
| 게시글·댓글 신고 | 신고한 이용자의 UID를 지우고, 신고 대상·사유·상세 내용·처리 상태 등은 남김 | 신고 검토와 허위 신고 처리 |
| 버그 제보·개선 제안 | 작성한 이용자의 UID와 기기 모델·Android 버전을 지우고, 분류·내용·재현 방법·앱 버전 등은 남김 | 서비스 개선 |

신고 상세 내용이나 제보 내용에 직접 적은 개인정보는 자동으로 지워지지 않습니다. 탈퇴하면 작성자 정보가 지워져 운영자가 해당 신고·제보를 찾기 어려우므로, 삭제를 원하시면 탈퇴하기 전에 4절 문의처로 요청하시거나, 요청 메일에 해당 신고·제보를 알아볼 수 있는 내용(작성 날짜, 내용 일부)을 함께 적어 주세요.

### 다. 보관 기간이 지나면 삭제되거나 Google 정책에 따라 처리되는 데이터

| 데이터 | 보관 기간 |
|--------|----------|
| 장애 복구용 데이터베이스 백업 | 탈퇴 후 최대 7일 |
| 서버 처리 기록(로그, UID가 포함될 수 있음) | 기본 30일 |
| Firebase Analytics 통계(앱 인스턴스 ID, 광고 ID 포함) | 이벤트 데이터 2개월, 사용자 단위 데이터는 마지막 앱 사용 후 14개월 |
| Firebase Crashlytics 오류 보고서(설치 식별자 포함)·사용 세션 정보 | 오류 보고서의 스택트레이스와 관련 식별자는 90일이 지나면 삭제 절차 시작, 그 밖의 오류 보고서 정보와 사용 세션 정보는 Google(Firebase) 정책에 따름 |

Firebase Analytics 통계와 Crashlytics 오류 보고서·사용 세션 정보는 계정과 연결되어 있지 않아 탈퇴할 때 따로 삭제되지 않습니다.
