# 개인정보처리방침

시행일: 2026년 11월 26일

Plant(이하 "앱")은 이용자의 개인정보를 소중히 여기며, 「개인정보 보호법」에 따라 아래와 같이 개인정보처리방침을 수립·공개합니다.

## 1. 수집하는 개인정보 항목 및 수집 방법

### 가. Google 로그인을 통해 자동 수집되는 정보

- Google 계정 이메일 주소
- Firebase 고유 식별자(UID)
- 가입 시각, 최근 로그인 시각 (Firebase Authentication이 기록)

※ Google 계정의 표시 이름, 프로필 사진 등은 수집·저장하지 않습니다.

### 나. 이용자가 직접 입력하는 정보

- 닉네임 (2~10자)
- 프로필 이미지 선택값 (앱이 제공하는 화분 레벨 이미지 중에서 선택, 사진 업로드 없음)

### 다. 서비스 이용 과정에서 생성되는 정보

- 학습 기록: 학습 시간, 학습 일지(제목·내용), 화분(학습 계획) 데이터
- 커뮤니티 활동: 게시글(게시글에 함께 공유한 학습 기록 포함), 댓글, 좋아요·북마크 내역 — 앱 내 다른 이용자에게 공개됩니다.
- 앱 내 재화: 골드, 아이템(정성·햇빛·물·비료·영양제·보너스 박스) 보유량, 보너스 박스 열기 결과 기록
- 출석 체크 기록
- 차단 목록: 이용자가 차단한 다른 이용자의 UID, 차단할 때 게시글·댓글에 표시된 그 이용자의 닉네임·프로필 이미지 선택값, 차단 시각 — 차단한 이용자 본인에게만 표시됩니다.
- 가입 동의 기록: 첫 로그인 때 만 14세 이상임을 확인하고 서비스 이용약관·개인정보처리방침에 동의한 시각
- 로그인 세션 식별값: 다른 기기에서 같은 계정으로 로그인하면 이전 기기를 로그아웃하기 위해 저장하는 임의의 값
- 실시간 학습 현황: 학습 중인 동안 닉네임, 프로필 이미지, 학습 카테고리, 학습 시간이 앱 내 다른 이용자에게 표시됩니다.

### 라. 신고, 버그 제보·개선 제안 시 수집되는 정보

아래 정보는 다른 이용자에게 공개되지 않으며, 운영자만 확인합니다.

- 게시글·댓글 신고: 신고한 이용자의 UID, 신고 대상(게시글·댓글), 신고 사유, 상세 내용("저작권 등 권리 침해", "기타" 사유를 고른 경우 이용자가 입력), 신고 일시, 처리 상태
- 버그 제보: 작성한 이용자의 UID, 분류, 내용, 재현 방법(입력한 경우), 앱 버전, 기기 모델, Android 버전, 작성 일시
- 개선 제안: 작성한 이용자의 UID, 분류, 내용, 앱 버전, 작성 일시

※ 버그 제보의 기기 모델·Android 버전은 제보 화면에 표시된 뒤 제보 내용과 함께 전송되며, 이용자 UID와 함께 저장됩니다.

### 마. Firebase Analytics를 통해 자동 수집되는 정보

- 앱 실행 횟수 및 세션 시간
- 기기 정보 (OS 버전, 기기 모델)
- 국가 및 언어 설정
- 앱 인스턴스 ID (앱 설치마다 무작위로 정해지는 값)
- 광고 ID (Android 기기의 광고 식별자)
- 앱 사용 이벤트 기록 (Firebase Analytics가 자동으로 기록하는 이벤트, 앱 오류 발생 기록 포함)

※ 위 정보는 이름·이메일·UID 등 이용자를 직접 알아볼 수 있는 정보와 연결하지 않으며, 서비스 개선 목적의 통계와 앱 오류 분석(1절 바)에만 사용합니다. 앱은 광고를 표시하지 않으며, 광고 ID를 광고 목적으로 사용하지 않습니다.

### 바. Firebase Crashlytics를 통해 자동 수집되는 정보

앱을 사용하는 동안 아래 정보를 자동으로 전송합니다. 오류 보고서는 앱이 오류로 강제 종료되거나 응답 없음(ANR, Android 11 이상)으로 종료된 경우 만들어지고(ANR은 다음 실행 때), 사용 세션 정보와 설치 식별자·기기 모델·OS 버전은 오류가 없어도 앱 사용을 시작할 때 전송됩니다.

- 비정상 종료 정보: 오류 발생 위치(스택트레이스), 오류 종류와 메시지, 발생 시각, 발생 당시 앱 상태(백그라운드 실행 여부, 화면 방향, 앱 프로세스 정보 등)
- 기기 정보: 기기 제조사·모델, OS 버전, 앱 버전, CPU 종류, 메모리·저장 공간 크기와 사용량, 배터리 잔량·충전 상태, 근접 센서 상태, 루팅 여부, CPU 코어 수, 에뮬레이터 여부
- Crashlytics 설치 식별자, Firebase 설치 ID (앱 설치마다 무작위로 정해지는 값)
- 오류 직전의 앱 사용 기록: 1절 마의 Firebase Analytics가 자동으로 기록하는 앱 사용 이벤트가 오류 보고서에 함께 붙습니다.
- 사용 세션 정보: Firebase가 무작위로 만드는 사용 세션 식별값, Firebase 설치 ID, 사용 시작 시각, 기기 제조사·모델, OS 버전, 앱 버전, 앱 프로세스 정보
- 전송할 때 함께 붙는 기기 환경 정보: 네트워크 연결 종류(와이파이·모바일 등), 통신사 국가·사업자 코드, 언어·국가 설정, 시간대, 기기 빌드 정보 (오류 보고서와 사용 세션 정보 모두)

※ 앱은 오류 보고서에 UID·닉네임·이메일·학습 내용을 따로 기록하지 않습니다. 바로 전송하지 못한 정보는 기기에 보관했다가 다음 실행이나 인터넷 연결 때 전송합니다.

### 사. 기기에만 저장되는 정보 (서버 미전송)

- 다크모드 설정
- 학습 세션 임시 백업 (비정상 종료 복구용)
- 학습 목표 임시 입력 내용
- 학습 결과 이미지 (이용자가 저장을 선택한 경우 기기 갤러리에 저장)

## 2. 개인정보의 수집 및 이용 목적

| 수집 항목 | 이용 목적 |
|-----------|----------|
| 이메일, UID | 회원 식별 및 로그인 관리 |
| 가입 동의 기록 | 만 14세 이상 확인과 서비스 이용약관·개인정보처리방침 동의 사실 확인 |
| 로그인 세션 식별값 | 한 계정이 여러 기기에서 동시에 로그인되지 않도록 관리 |
| 닉네임 | 커뮤니티 활동 시 표시 이름 |
| 프로필 이미지 선택값 | 커뮤니티 활동·실시간 학습 현황에 표시 |
| 학습 기록 | 학습 진행 추적 및 식물 성장 반영 |
| 커뮤니티 활동 | 게시글·댓글 작성 및 이용자 간 상호작용 제공 (앱 내 다른 이용자에게 공개) |

| 출석 체크 기록 | 하루 한 번 출석 확인 및 출석 보상 지급 |
| 차단 목록 | 차단한 이용자의 게시글·댓글을 내 화면에서 숨기고, 차단 목록 화면에서 해제할 수 있도록 표시 |
| 실시간 학습 현황 | 같은 분야를 공부 중인 이용자 표시 |

| 버그 제보·개선 제안 | 오류 원인 확인 및 서비스 개선, 제보에 대한 처리 |
| 자동 수집 통계 (기기·세션 정보, 앱 인스턴스 ID, 광고 ID, 앱 사용 이벤트) | 서비스 이용 통계 분석 및 안정성 분석 |
| 오류 보고서 (비정상 종료 정보, 기기 정보, 설치 식별자, 오류 직전의 앱 사용 기록), 사용 세션 정보, 전송 환경 정보 | 앱 오류 원인 분석, 오류 없이 사용한 비율 등 안정성 지표 확인 및 개선 |

## 3. 개인정보의 보유 및 이용 기간

이용자의 개인정보는 서비스 이용 기간 동안 보유하며, **회원 탈퇴 시 즉시 삭제하거나 개인을 알아볼 수 없도록 처리**합니다. 다만 다른 이용자의 차단 목록에 남는 기록(아래 가의 ※), 신고·제보 내용에 직접 적은 개인정보(아래 나의 ※), 백업·운영 기록(아래 다)은 해당 항목에 적은 대로 처리합니다.

### 가. 탈퇴 시 삭제되는 정보

- 계정 정보(이메일, UID, 가입·최근 로그인 시각), 닉네임, 프로필 이미지 선택값, 가입 동의 기록, 로그인 세션 식별값
- 학습 기록, 화분 데이터, 재화·아이템, 보너스 박스 열기 결과 기록, 출석 체크 기록
- 내가 작성한 게시글(게시글에 달린 댓글 포함)과 커뮤니티 활동 내역
- 다른 이용자의 게시글에 남긴 좋아요·북마크
- 내가 만든 차단 목록
- 실시간 학습 현황

※ 다른 이용자가 나를 차단한 기록(그 이용자의 차단 목록에 있는 내 UID와, 차단할 때 게시글·댓글에 표시된 내 닉네임·프로필 이미지 선택값)은 탈퇴해도 지워지지 않고, 그 이용자가 차단을 해제하거나 탈퇴할 때까지 남습니다. 이 기록은 그 이용자에게만 표시됩니다.

### 나. 탈퇴 후 개인을 알아볼 수 없는 형태로 남는 정보

- 다른 이용자의 게시글에 남긴 댓글: 댓글 내용은 "- 삭제된 댓글입니다. -"로, 작성자는 "(알 수 없음)"으로 바뀌고 댓글 자리만 남습니다.
- 신고 정보: 신고한 이용자의 UID를 지우고, 신고 대상·사유·상세 내용·처리 상태는 신고 검토와 허위 신고 처리를 위해 남깁니다.
- 버그 제보·개선 제안: 작성한 이용자의 UID와 기기 모델·Android 버전을 지우고, 분류·내용·재현 방법·앱 버전은 서비스 개선을 위해 남깁니다.

※ 신고 상세 내용이나 제보 내용에 이용자가 직접 적은 개인정보는 자동으로 지워지지 않으므로, 개인정보를 적지 않도록 주의해 주세요. 탈퇴하면 작성자 정보가 지워져 해당 신고·제보를 찾기 어려우므로, 삭제를 원하시면 탈퇴하기 전에 아래 연락처로 요청하시거나, 요청할 때 해당 신고·제보를 알아볼 수 있는 내용(작성 날짜, 내용 일부)을 함께 적어 주세요.

### 다. 백업 및 운영 기록

- 장애 복구를 위한 데이터베이스 백업에는 탈퇴 후에도 최대 7일 동안 데이터가 남을 수 있으며, 이후 자동으로 삭제됩니다. 백업은 장애 복구 외의 목적으로 사용하지 않습니다.
- 서버 처리 기록(로그)에 UID가 포함될 수 있으며, Google Cloud 로그 보관 기간(기본 30일)이 지나면 자동으로 삭제됩니다.
- Firebase Analytics 통계(앱 인스턴스 ID, 광고 ID 포함)는 계정과 연결되어 있지 않아 탈퇴할 때 따로 삭제되지 않습니다. Google Analytics에서 이벤트 데이터는 2개월, 사용자 단위 데이터는 마지막으로 앱을 사용한 때부터 14개월이 지나면 매월 자동으로 삭제되며, 그 뒤에는 이용자를 알아볼 수 없는 집계 통계만 남습니다.
- Firebase Crashlytics 오류 보고서(설치 식별자 포함)와 사용 세션 정보도 계정과 연결되어 있지 않아 탈퇴할 때 따로 삭제되지 않습니다. 오류 보고서의 스택트레이스와 관련 식별자는 90일이 지나면 운영·백업 시스템에서 삭제하는 절차가 시작되며, 그 밖의 오류 보고서 정보와 사용 세션 정보의 보관 기간은 Google(Firebase)의 정책을 따릅니다.

## 4. 개인정보의 파기 절차 및 방법

이용자가 회원 탈퇴를 요청하면 해당 개인정보를 지체 없이 파기합니다.

- **파기 절차**: 이용자가 앱 내 마이페이지에서 탈퇴를 요청하면, 해당 계정과 연관된 데이터를 3절에 적은 방식대로 즉시 삭제하거나 개인을 알아볼 수 없도록 처리합니다. 가입(닉네임 설정)을 마치지 않은 계정은 9절의 삭제 요청을 받으면 지체 없이 3절에 적은 방식대로 삭제하거나 개인을 알아볼 수 없도록 처리합니다. 앱을 설치하지 않았거나 로그인할 수 없는 경우에도 12절 연락처로 삭제를 요청하면 같은 방식으로 처리합니다 (요청 방법은 [계정 삭제 안내](https://plant-82b09.web.app/account-deletion.html) 참고).
- **파기 방법**: 전자적 파일 형태의 정보는 기록을 재생할 수 없는 기술적 방법을 사용하여 삭제합니다.

## 5. 개인정보의 제3자 제공

앱은 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만, 서비스 운영을 위해 아래 플랫폼을 이용합니다.

| 위탁 업체 | 위탁 내용 |
|-----------|----------|
| Google (Firebase) | 인증(Authentication), 데이터 저장(Firestore, 서울 리전), 서버 기능 실행(Cloud Functions, 서울 리전), 호스팅(Hosting), 사용 통계 분석(Analytics), 오류 보고서 수집·분석(Crashlytics) |

Firebase의 개인정보 처리에 관한 사항은 [Firebase 개인정보 보호 및 보안](https://firebase.google.com/support/privacy) 페이지를 참고해 주세요.

## 6. 이용자의 권리 및 행사 방법

이용자는 언제든지 다음과 같은 권리를 행사할 수 있습니다.

- **닉네임 변경**: 앱 내 마이페이지에서 직접 변경

## 7. 자동 수집 장치의 설치·운영 및 거부

앱은 쿠키(Cookie)를 사용하지 않으나, 서비스 개선을 위해 Firebase Analytics를 통해 아래와 같은 사용 통계를 자동으로 수집합니다.

- 앱 실행 횟수 및 세션 시간
- 기기 정보 (OS 버전, 기기 모델)
- 국가 및 언어 설정
- 앱 인스턴스 ID (앱 설치마다 무작위로 정해지는 값)
- 광고 ID (Android 기기의 광고 식별자)
- 앱 사용 이벤트 기록 (Firebase Analytics가 자동으로 기록하는 이벤트, 앱 오류 발생 기록 포함)

위 정보는 이용자를 직접 알아볼 수 있는 정보와 연결하지 않으며, Google의 정책에 따라 처리됩니다.

광고 ID 수집을 원하지 않으면 기기 설정의 **개인 정보 보호 > 광고**에서 광고 ID를 삭제할 수 있습니다. 같은 메뉴의 재설정은 광고 ID를 새 값으로 바꾸는 기능이며 수집을 멈추지는 않습니다. 기기와 Android 버전에 따라 메뉴 이름과 위치가 다를 수 있습니다.

또한 앱 오류를 분석하기 위해 Firebase Crashlytics로 1절 바의 정보를 자동으로 수집합니다. 앱 안에서 이 정보의 전송을 따로 끄는 설정은 제공하지 않으므로, 더 이상 전송을 원하지 않으면 앱을 삭제해 주세요.

자세한 사항은 [Google의 파트너 사이트 개인정보 보호](https://policies.google.com/technologies/partner-sites) 페이지를 참고해 주세요.

## 8. 개인정보의 안전성 확보 조치

- 모든 데이터 전송은 HTTPS(SSL/TLS)로 암호화됩니다.

## 9. 만 14세 미만 아동의 개인정보

본 서비스는 만 14세 미만은 가입할 수 없으며, 만 14세 미만 아동의 개인정보를 의도적으로 수집하지 않습니다. 첫 로그인 때 만 14세 이상인지 확인하며, 확인하지 않으면 닉네임 설정(가입)을 마칠 수 없습니다. 다만 이 확인 전에도 Google 로그인만으로 1절 가의 정보와 로그인 세션 식별값이 저장되고, 1절 마·바의 정보는 앱을 실행할 때부터 수집됩니다. 가입을 마치지 않은 계정은 앱에서 탈퇴할 수 없으므로, 가입에 사용한 Google 계정 이메일로 12절 연락처에 요청하면 계정과 서버에 저장된 데이터를 삭제합니다(백업·서버 처리 기록과 1절 마·바의 정보는 3절 다와 같이 처리됩니다). 앱은 Google 계정을 통한 로그인만 지원하며, Google 계정의 연령 정책에 따릅니다. 만 14세 미만의 이용이 확인될 경우 해당 계정과 데이터를 삭제할 수 있습니다.
