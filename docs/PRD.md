# Plant PRD (Product Requirements Document)


## 1. 배경 및 문제 정의

### 1-1. 문제

대부분의 학습 보조 앱은 **개인 기록**에만 치중하여 두 가지 한계가 존재한다.

| 한계 | 설명 |
|------|------|
| **동기부여 부재** | 혼자 공부하면 의지가 꺾이기 쉽고, 타인과의 비교·소통을 통한 자극이 없다 |
| **학습 계획 공유 부재** | 학습 자료와 노하우가 여러 곳에 흩어져 있어 무엇을 참고해야 할지 판단하기 어렵고, 내 기록을 공유할 수단이 제한적이다 |

### 1-2. 솔루션

**Plant**는 학습 시간을 바탕으로 **나만의 식물을 키우며 학습하는 재미**를 부여하고, **게시판을 통해 동료들과 학습 기록을 공유**하며 꾸준히 공부할 수 있는 환경을 제공한다.

### 1-3. 핵심 가치

| 가치 | 설명 |
|------|------|
| 🌱 **성장의 시각화** | 공부 시간이 화분의 성장으로 이어져, 추상적인 노력이 눈에 보이는 성과로 변환된다 |
| 👥 **함께 공부하는 경험** | 실시간으로 같은 분야를 공부하는 사용자를 확인하여 소속감과 동기부여를 얻는다 |
| 📝 **기록과 공유** | 학습 기록을 체계적으로 관리하고, 커뮤니티를 통해 다른 사용자와 나눌 수 있다 |

## 2. 대상 사용자

| 유형 | 설명 | 핵심 니즈 |
|------|------|-----------|
| **기록형 학습자** | 공부 시간을 측정하고, 학습 기록이 쌓여가는 과정을 시각적으로 확인하고 싶은 사용자 | 학습 현황의 가시화 |

| **전략형 학습자** | 다른 유저들이 공유한 학습 계획과 노하우를 참고하여 나만의 학습 경로를 설계하고 싶은 사용자 | 학습 전략 참고 |

**정렬 기준 (5종):**

| 정렬 기준 | 필드 | 설명 |

## 4. 기술 아키텍처

### 4-1. 기술 스택

| 분류 | 기술 |
|------|------|
| Language | Kotlin |
| UI Framework | Jetpack Compose + Material 3 |
| Architecture | MVVM + Clean Architecture, Feature-based 패키지 구조 |
| DI | Hilt (`@HiltViewModel`, `@Inject`, `@Module`/`@InstallIn`) |
| Async | Coroutines & Flow |
| Navigation | Jetpack Navigation Compose (Type-safe, kotlinx.serialization) |
| Backend | Firebase Auth, Cloud Firestore, FCM, Cloud Functions |
| Local Storage | Preferences DataStore |
| Image Loading | Coil |
| Build | Gradle KTS, KSP |

### 4-2. 아키텍처 레이어

```
┌─────────────────────────────────────────────┐
│  Presentation Layer                         │
│  ┌───────────┐  ┌─────────────────────────┐ │
│  │ UI        │  │ ViewModel               │ │
│  │ (Compose) │──│ (StateFlow, UiState)    │ │
│  └───────────┘  └──────────┬──────────────┘ │
├────────────────────────────┼────────────────┤
│  Domain Layer              │                │
│  ┌─────────────┐  ┌───────┴──────────────┐ │
│  │ UseCase     │  │ Repository (Interface)│ │
│  │             │──│                       │ │
│  │ Model       │  │ Result<T>             │ │
│  └─────────────┘  └───────┬──────────────┘ │
├────────────────────────────┼────────────────┤
│  Data Layer                │                │
│  ┌─────────────┐  ┌───────┴──────────────┐ │
│  │ Repository   │  │ DataSource           │ │
│  │ (Impl)      │──│ Remote / Local       │ │
│  │ Mapper      │  │ (Firebase, DataStore)│ │
│  └─────────────┘  └─────────────────────┘ │
└─────────────────────────────────────────────┘
```
