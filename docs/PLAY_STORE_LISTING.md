# Play 스토어 등록정보 초안 (#786)

Play Console > 스토어 등록정보 > **기본 스토어 등록정보**(한국어 ko-KR)에 넣을 문구·그래픽·스크린샷을 정리한 문서다. 콘솔 화면의 항목 이름·제한은 바뀔 수 있으므로, 입력할 때는 **그 시점의 콘솔 안내를 기준**으로 하고 이 문서와 다르면 이 문서를 고친다. 앱 콘텐츠(데이터 보안·포그라운드 서비스 등) 답변은 `docs/PLAY_CONSOLE.md`.

근거 표시: **(코드)** 레포 코드에서 직접 확인(develop `cbc9cdef` 기준), **(정책)** Play 도움말 원문 확인(2026-11-28), **(미확인)** 아직 확인하지 않음.

## 0. 이 문서와 함께 바꿔야 하는 것

설명 문구는 "앱에 실제로 있는 기능"만 적었다(1절 표). 아래가 바뀌면 같은 PR에서 이 문서의 설명과 콘솔 등록정보를 함께 고친다.

## 2. 설명 문구

작성 기준 (정책: [메타데이터 정책](https://support.google.com/googleplay/android-developer/answer/9898842), 원문 확인 2026-11-28, 페이지에 갱신일 표시 없음):

- "1위", "최고", "인기", "추천", "NEW", "무료", "할인" 같은 순위·실적·가격 표현, 다른 앱 이름, 키워드 나열, 출처 없는 사용 후기를 넣지 않는다
- 간단한 설명: 80자 이하, 이모지·특수문자·줄바꿈 없음, "지금 다운로드" 같은 행동 유도 없음, 마침표는 문장이 여러 개일 때만
- 자세한 설명: 4000자 이하, 간단한 설명을 그대로 되풀이하지 않음
- 앱 화면과 같은 해요체, 이모지 없음 (UI 통일 규칙)
- 콘텐츠 등급 설문에서 "주로 교육용 제품"을 "아니요"로 답했으므로, 강의·문제 같은 교육 콘텐츠를 주는 것처럼 쓰지 않는다 (공부 시간을 기록·관리하는 앱으로 씀)

### 앱 이름 (30자)

```text
Plant
```

입력됨. 계정 삭제 안내 페이지의 앱 이름과 맞는지는 `docs/PLAY_CONSOLE.md` 6절 확인 목록.

### 간단한 설명 (80자, 지금 43자)

```text
스톱워치로 공부 시간을 재고 쌓인 시간으로 나만의 화분을 키우는 공부 기록 앱
```

### 자세한 설명 (4000자, 지금 공백·줄바꿈 포함 1113자)

"최고·최저 기록"은 리포트 화면의 항목 이름이라 순위 표현이 아니다.

```text
Plant는 공부한 시간으로 화분을 키우며 공부 습관을 만드는 앱이에요.
공부할 주제마다 화분을 하나씩 만들고, 공부할수록 자라는 화분으로 꾸준함을 눈으로 확인해 보세요.

[공부 시간 기록]
- 화분을 고르고 공부를 시작하면 스톱워치가 시간을 재요. 잠시 멈췄다가 이어서 할 수도 있어요.
- 오늘의 학습 목표를 적어 두고, 공부하면서 하나씩 체크할 수 있어요.
- 다른 앱을 쓰는 동안에도 알림에서 공부 시간을 확인할 수 있어요.
- 학습 화면에서 같은 태그로 지금 공부 중인 사람이 몇 명인지 볼 수 있어요.
- 공부를 마치면 공부한 시간, 목표, 받은 보상을 결과 화면에서 보여 주고, 결과를 이미지로 저장할 수 있어요.

[화분 키우기]
- 화분은 Lv.0 씨앗부터 Lv.6까지 자라요.
- 누적 공부 시간을 채우고 성장 아이템(정성, 햇빛, 물, 비료, 영양제)을 모으면 화분을 레벨업할 수 있어요.
- 한 번에 1시간 이상 공부하면 학습 보상으로 성장 아이템과 보너스 박스를 받아요.
- 하루 한 번 출석체크를 하면 출석 일수에 따라 보상을 받아요.
- 내 화분에서 지금 키우는 화분과 다 키운 화분을 모아 볼 수 있어요.
- 화분 레벨이 오를수록 고를 수 있는 프로필 이미지가 늘어나요.

[리포트]
- 달력에서 날짜별 공부 기록을 확인할 수 있어요.
- 일간 리포트에서는 그날의 총 공부 시간과 최고·최저 기록을, 월간 리포트에서는 하루 평균, 최장 연속 공부 일수, 날짜별 공부 시간 그래프를 볼 수 있어요.

[커뮤니티]
- 화분에 쌓인 공부 기록을 골라 게시글로 공유할 수 있어요.
- 다른 사람이 공유한 공부 기록과 글을 태그와 검색으로 찾아보고, 댓글, 좋아요, 북마크로 소통해요.
- 불쾌한 글이나 댓글은 신고할 수 있고, 원하지 않는 사용자는 차단할 수 있어요.

[그 밖의 기능]
- 다크모드를 켜고 끌 수 있어요.
- 앱에서 바로 버그를 제보하거나 개선사항을 제안할 수 있어요.

[이용 안내]
- Google 계정으로 로그인하며, 만 14세 이상만 가입할 수 있어요.
- 커뮤니티에 올린 글과 댓글, 닉네임, 프로필 이미지는 다른 사용자에게 보여요.
- 한 계정은 한 기기에서만 로그인 상태가 유지돼요. 다른 기기에서 로그인하면 이전 기기는 로그아웃돼요.
```

## 3. 그래픽 이미지 (1024×500)

- 파일: `docs/store/feature_graphic.png` (1024×500, 24비트 PNG, 알파 없음, 약 45KB)
- 다시 만들기: `python -I docs/store/feature_graphic.py <레포 경로> docs/store/feature_graphic.png docs/store/feature_graphic_tagline.json` (Pillow 필요. 문구는 JSON 파일에서 읽음)
- 구성: 스플래시 배경색(`splash_background` `#EEF5E4`), 왼쪽에 앱 글꼴(`res/font/bold.ttf`, 경기천년제목)로 "Plant"와 로그인 화면 문구 "공부할수록 자라는 나만의 화분"(`SignInScreen.kt`), 오른쪽에 앱의 화분 성장 이미지 Lv.1·Lv.3·Lv.6(`ic_pot_growth_lv*.png`)
- 정책 대조 ([미리보기 저작물 추가](https://support.google.com/googleplay/android-developer/answer/9866151), 2026-11-28):
  - 앱 아이콘(스톱워치 고리 + 새싹)을 그대로 넣지 않음 ("앱 아이콘과 겹치는 브랜드 요소" 피하기)
  - 순수 흰색·검은색·짙은 회색 배경이 아님
  - 기기 그림, 스토어 배지, 순위·가격 문구 없음. 글자는 이름과 한 줄 문구만
  - 중요한 요소는 가장자리에서 40px 이상 떨어뜨림 (화분 오른쪽 끝 x=984)
- 대체 텍스트(140자 이하): `Plant 로고와 공부할수록 자라는 나만의 화분 문구, 새싹부터 큰 식물까지 자라는 화분 세 개` (미확인: 기본 스토어 등록정보에 대체 텍스트 칸이 있는지 콘솔에서 확인)
- 팀 확인: 휴대전화의 작은 그래픽 크기에서 한 줄 문구가 읽히는지

### 찍는 방법 (제안)

- 9:16을 맞추려면 1080×1920 화면의 에뮬레이터(Google Play 시스템 이미지)에 release APK를 설치해 찍는 것이 간단하다. 실기기는 화면 비율이 길어(예: 노트20 1080×2316) 9:16이 아니고, 해상도를 바꾸는 `wm size`는 기기 설정을 건드리므로 쓰지 않는다
- 상태 표시줄 정리: 에뮬레이터에서 시스템 UI 데모 모드 (`adb shell settings put global sysui_demo_allowed 1` 뒤 `am broadcast -a com.android.systemui.demo -e command enter` 등). 끝나면 `-e command exit`
- 캡처: `adb exec-out screencap -p > 01_home.png`. 캡처 뒤 크기·알파 채널을 확인해(알파가 있으면 RGB로 변환) 올린다
- 미확인: 에뮬레이터에서 release 빌드가 운영 Firebase에 붙는지. App Check를 Firestore·함수에 강제한 뒤라면 Play Integrity가 실패할 수 있어(#608), 그때는 Play 시스템 이미지·디버그 토큰 등 방법을 다시 정한다. Google 로그인은 에뮬레이터에 샘플 Google 계정을 추가해야 함
