## 1. 전체 화면 맵

### 1-1. Navigation 구조

```
앱 실행
  │
  ▼
SplashScreen ─── 자동 로그인 판단
  │
  ├─ 세션 없음 / 유저 없음 / 첫 로그인 ──▶ SignInScreen
  │                                          │
  │                                          ├─ Google 로그인 (기존 유저) ──▶ HomeMain
  │                                          └─ Google 로그인 (신규) ──▶ 닉네임 설정 ──▶ HomeMain
  │
  └─ 세션 + 유저 정상 ──▶ HomeMain
                           │
                           ▼
                    BottomNavigation (5개 탭)
                    ┌────────────────────────────────────────────┐
                    │                                            │
            ┌───────┼───────┬────────┬────────┬──────────┐       │
            ▼       ▼       ▼        ▼        ▼          │       │
         커뮤니티  나의정원   홈     리포트   마이페이지      │       │
                                                         │       │
                     각 탭에서 하위 화면으로 이동 ──────────┘       │
                      뒤로가기로 탭 화면 복귀 ──────────────────────┘
```

### 1-2. BottomBar 탭 구성 ✅

| 순서 | 탭 이름 | Route | 아이콘 |
|:----:|--------|-------|--------|
| 1 | 커뮤니티 | `CommunityList` | ic_bottom_community |
| 2 | 나의 정원 | `PotList` | ic_bottom_pot |
| 3 | 홈 (중앙) | `HomeMain` | ic_bottom_home |
| 4 | 리포트 | `Report` | ic_bottom_report |
| 5 | 마이페이지 | `Mypage` | ic_bottom_mypage |

**탭 전환 규칙**:
- 모든 탭은 `popUpTo(HomeMain) { inclusive = false }` + `launchSingleTop = true`
- HomeMain이 백스택 루트로 항상 유지됨
- 같은 탭 재클릭 시 무시

## 2. 인증 플로우

### 2-1. 신규 가입 (Google)

```
┌──────────┐    Google 계정    닉네임 설정    ┌──────────┐
│          │      선택     ,    (2~10자)     │          │
│  SignIn  │ ─────────────────────────▶     │ HomeMain │
│  Screen  │                                │          │
│          │                                │          │
└──────────┘                                └──────────┘
     │
     │  idToken 추출
     │  Firebase Auth 인증
     │  유저 문서 생성 (isFirstLogin=true)
     │
     ▼
  ResolveUserSession
  → isFirstLogin == true
  → SignUpScreen으로 이동
```

**전제조건**: 앱에 Google 계정이 연동되어 있어야 함  
**종료조건**: 닉네임 설정 완료 후 HomeMain 진입

### 2-2. 기존 유저 로그인 (Google)

```
┌──────────┐    Google 계정     ┌──────────┐
│          │      선택          │          │
│  SignIn  │ ──────────────▶   │ HomeMain │
│  Screen  │                   │          │
└──────────┘                   └──────────┘
     │
     ▼
  ResolveUserSession
  → isFirstLogin == false
  → HomeMain으로 직행
```

### 2-3. 자동 로그인

```
┌──────────┐                   ┌──────────┐
│          │  세션 + 유저 정상   │          │
│  Splash  │ ──────────────▶   │ HomeMain │
│  Screen  │                   │          │
│          │  세션 없음 / 실패   ┌──────────┐
│          │ ──────────────▶   │  SignIn  │
└──────────┘                   └──────────┘
```

### 2-4. 로그아웃

```
┌──────────┐    로그아웃 확인    ┌──────────┐
│          │    다이얼로그       │          │
│  Mypage  │ ──────────────▶   │  SignIn  │
│  Screen  │                   │  Screen  │
└──────────┘                   └──────────┘
                                    │
                               popUpTo(0)
                               (전체 백스택 클리어)
```

### 2-5. 회원탈퇴

```
┌──────────┐   1단계 확인   ┌──────────┐   2단계 확인   ┌──────────┐
│  Mypage  │ ──────────▶   │ 1차 확인  │ ──────────▶   │ 2차 확인  │
│  Screen  │   다이얼로그   │ Dialog   │   다이얼로그    │ Dialog   │
└──────────┘               └──────────┘               └────┬─────┘
                                                           │
                                                    데이터 삭제 후
                                                           │
                                                           ▼
                                                      ┌──────────┐
                                                      │  SignIn  │
                                                      │  Screen  │
                                                      └──────────┘
```

### 2-6. 세션 만료 (어느 화면에서든 발생 가능)

```
┌──────────┐   EnsureCurrentUser   ┌──────────┐   세션만료      ┌──────────┐
│  아무     │   → null 감지         │  signOut  │   다이얼로그    │  SignIn  │
│  화면     │ ──────────────────▶   │  + 이동   │ ─────────────▶ │  Screen  │
└──────────┘                       └──────────┘   표시           └──────────┘

순서: signOut() → SignInScreen 이동 → 세션 만료 다이얼로그 표시
```

## 3. 홈 · 화분 플로우

### 3-1. 홈 메인 화면

```
┌──────────────────────────────────────────────────────────┐

│  ┌─────────────────────────────────────┐                 │

│  │  (이미지, 이름, 태그, 레벨, 학습시간)   │                 │
│  └────────────┬────────────────────────┘                 │
│               │                                          │
│    ┌──────────┼──────────┬───────────────┐               │
│    ▼          ▼          ▼               ▼               │
│  학습시작   화분변경      화분추가        출석체크              │
│    │       (다이얼로그)  (NewBornTree)  (AttendanceDialog)  │
│    │          │            │               │               │
└────┼──────────┼────────────┼───────────────┼───────────────┘
     │          │            │               │
     ▼          ▼            ▼               ▼
  Studying   화분선택     NewBornTree   AttendanceCheck
  Screen     Dialog       Screen        Dialog
```

### 3-2. 화분 생성 플로우

```
진입 경로 (2가지):
  ① HomeScreen 화분변경 다이얼로그 → "+새로운 화분 만들기"
  ② 하단바 화분 아이콘 → 나만의 정원 → 우측 상단 + 버튼

         ┌──────────────────────────┐               ┌──────────┐
         │      NewBornTree         │    생성 완료   │          │
         │                          │ ──────────▶   │   Home   │
         │  1. 상위 태그 선택         │               │   Main   │
         │  2. 하위 태그 선택         │               │          │
         │  3. 이름 입력 (≤20자)      │              └──────────┘
         │  4. "생성" 탭             │
         └──────────────────────────┘
```

### 3-3. 화분 상세 · 관리 플로우

```
┌──────────┐   화분 탭    ┌──────────┐   화분 탭    ┌────────────────┐
│  Home /  │ ──────────▶ │  PotList │ ──────────▶ │ StudyPlanDetail│
│  PotList │             │  Screen  │             │    Screen      │
└──────────┘             └──────────┘             └───────┬────────┘
                                                          │
                              ┌────────────────┬──────────┼──────────┬────────────┐
                              ▼                ▼          ▼          ▼            ▼
                         이름 변경          학습 시작    학습 완료     삭제       학습기록
                         Dialog          Studying     처리         확인Dialog   목록
                              │            Screen     (토스트)        │          │
                              ▼                │         │            ▼          ▼
                         이름 갱신              │      토스트 표시   화분 삭제   StudyLog
                                               ▼                  (다른 화분   DetailDialog
                                          StudyResult   으로 대체)              │
                                           Screen                              ▼
                                                                           기록 삭제/공유
```

### 3-4. 나의 정원 (PotList) 탭 필터

```
┌──────────────────────────────────────┐

│                                      │
│   [공부 중 (기본)]       [완료]        │
```

## 7. 화면 전환 매트릭스

### 7-1. 전체 Route 목록

| Route | 화면명 | BottomBar | 파라미터 |
|-------|--------|:---------:|---------|
| `SignIn` | 로그인 | ✗ | — |
| `SignUp` | 닉네임 설정 | ✗ | — |
| `HomeMain` | 홈 | ✓ | — |
| `PotList` | 나의 정원 | ✓ | — |
| `CommunityList` | 커뮤니티 목록 | ✓ | — |
| `Report` | 리포트 | ✓ | — |
| `Mypage` | 마이페이지 | ✓ | — |
| `NewBornTree` | 화분 생성 | ✗ | — |
| `StudyPlanDetail` | 화분 상세 | ✗ | `potId` |
| `Studying` | 학습 (스톱워치) | ✗ | `potId`, `tagId`, `tagName`, `title`, `level` |
| `StudyResult` | 학습 결과 | ✗ | `timestamp`, `tag`, `title`, `log`, `time`, `potId`, `level` |
| `CommunityPost` | 게시글 작성/수정 | ✗ | `postId?`, `potId?`, `tagId?`, `tagName?`, `title?`, `studyLogIds?` |
| `CommunityDetail` | 게시글 상세 | ✗ | `postId` |
| `CommunityActivity` | 활동 내역 | ✗ | — |

> **미사용 Route** (Routes.kt에 정의만 존재, NavHost 등록 및 navigate 호출 없음):
> `PotDetail(potId)`, `StudyCompleted`, `StudyCompletedDetail(potId)`
> — 향후 구현 예정이거나 제거 대상. 현재 앱에서는 동작하지 않음.

| 출발 화면 | → 도착 화면 | 트리거 |

| Splash | SignIn | 자동 로그인 실패 |

| SignIn | SignUp | Google 로그인 (신규 유저) |

| HomeMain | NewBornTree | 화분변경 다이얼로그 → "+새로운 화분 만들기" |
| HomeMain | PotList | BottomBar 탭 |
| HomeMain | StudyPlanDetail | 대표 화분 상세 |
| PotList | StudyPlanDetail | 화분 카드 탭 |
| StudyPlanDetail | Studying | "학습 시작" |
| StudyPlanDetail | CommunityPost | 학습 기록 공유 |
| Studying | StudyResult | 학습 종료 + 저장 |
| StudyResult | HomeMain | "확인" 탭 |
| StudyResult | CommunityPost | 커뮤니티 공유 토글 |
| CommunityList | CommunityDetail | 게시글 카드 탭 |
| CommunityList | CommunityPost | FAB "글 작성" |
| CommunityDetail | CommunityPost | "수정" (본인 글) |
| CommunityDetail | CommunityList | "삭제" 완료 |
| Mypage | CommunityActivity | "활동 내역" |
| Mypage | SignIn | 로그아웃 / 회원탈퇴 |

| 아무 화면 | SignIn | 세션 만료 이벤트 |
