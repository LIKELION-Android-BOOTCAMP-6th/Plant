## 1. 전체 화면 맵

### 1-1. 전체 흐름 구조

```
앱 실행 → 스플래시 (자동 로그인 판단)
  │
  ├─ 세션 없음 / 유저 없음 / 첫 로그인 → 로그인 화면
  │                                       ├─ Google 로그인 (기존 유저) → 홈
  │                                       └─ Google 로그인 (신규) → 닉네임 설정 → 홈
  │
  └─ 세션 + 유저 정상 → 홈
                         │
                         ▼
                  하단바 (5개 탭): 커뮤니티 / 나의 정원 / 홈 / 리포트 / 마이페이지
                  각 탭에서 하위 화면으로 이동, 뒤로가기로 탭 화면 복귀
```

### 1-2. 하단바 탭 구성

| 순서 | 탭 이름 |
|:----:|--------|
| 1 | 커뮤니티 |
| 2 | 나의 정원 |
| 3 | 홈 (중앙) |
| 4 | 리포트 |
| 5 | 마이페이지 |

**탭 전환 규칙**:
- 홈이 항상 백스택 루트로 유지됨
- 같은 탭 재클릭 시 무시

## 2. 인증 플로우

### 2-1. Google 로그인

```
로그인 화면 → Google 계정 선택
  │
  ├─ 신규 유저 → 닉네임 설정 (2~10자) → 홈
  └─ 기존 유저 → 바로 홈 진입
```

**전제조건**: 기기에 Google 계정이 연동되어 있어야 함
**신규 유저**: 닉네임 설정(2~10자, 중복 불가) 후 홈 진입
**기존 유저**: Google 계정 선택만으로 홈 직행

### 2-2. 자동 로그인

```
스플래시 화면
  ├─ 세션 + 유저 정상 → 홈으로 진입
  └─ 세션 없음 / 실패 → 로그인 화면으로 이동
```

### 2-3. 로그아웃

```
마이페이지 → [로그아웃] → 확인 다이얼로그 → 로그인 화면으로 이동
```

### 2-4. 회원탈퇴

```
마이페이지 → [회원탈퇴]
  │
  ├─ 1차 확인 다이얼로그
  ├─ 2차 확인 다이얼로그
  ├─ Google 계정 재인증
  ├─ 데이터 삭제
  └─ 로그인 화면으로 이동
```

### 2-5. 세션 만료 (어느 화면에서든 발생 가능)

```
사용 중 세션 만료 감지 → 자동 로그아웃 → 로그인 화면 이동 → 세션 만료 안내 표시
```

## 3. 홈 · 화분 플로우

### 3-1. 홈 메인 화면

**화면 구성**: 대표 화분 영역 (이미지, 이름, 태그, 레벨, 학습 시간)

**진입 가능 액션**:
- **학습 시작** → 학습 화면으로 이동
- **화분 변경** → 화분 선택 다이얼로그
- **화분 추가** → 화분 생성 화면으로 이동
- **출석체크** → 출석체크 다이얼로그

### 3-2. 화분 생성 플로우

**진입 경로** (2가지):
1. 홈 → 화분변경 다이얼로그 → "+새로운 화분 만들기"
2. 하단바 나의 정원 → 우측 상단 + 버튼

**생성 단계**: 상위 태그 선택 → 하위 태그 선택 → 이름 입력(≤20자) → [생성] → 홈으로 복귀

### 3-3. 화분 상세 · 관리 플로우

**진입**: 홈 또는 나의 정원 → 화분 카드 탭 → 화분 상세

**화분 상세에서 가능한 액션**:
- **이름 변경** → 이름 변경 다이얼로그
- **학습 시작** → 학습 화면
- **학습 완료 처리** → 완료 토스트
- **삭제** → 삭제 확인 다이얼로그 → 다른 화분으로 대체
- **학습 기록 목록** → 기록 상세 다이얼로그 → 기록 삭제/공유

**화분 성장 (레벨업) 조건**: Lv.0 ~ Lv.6 (7단계), 누적 학습 시간 + 아이템 소비 이중 조건 → 상세는 PRD 참조

### 3-4. 나의 정원 (화분 목록) 필터 · 정렬

**필터**: 전체 / 공부 중 (기본) / 완료

**정렬 기준** (5종): 생성일 최신순(기본), 누적 학습 시간순, 레벨순, 이름순(가나다), 최근 학습순

**진입 가능 액션**:
- 화분 카드 탭 → 화분 상세 화면
- 우측 상단 [+] → 화분 생성 화면

### 3-5. 출석체크 플로우

```
홈 → 출석체크 아이콘 탭
  │
  ▼
┌──────────────────────────────────────────────────┐
│              출석체크 다이얼로그                    │
│                                                  │
│  ┌──────────────────────────────────────────┐    │
│  │          28일 출석판                      │    │
│  │  ┌──┬──┬──┬──┬──┬──┬──┐                  │    │
│  │  │ 1│ 2│ 3│ 4│ 5│ 6│ 7│  ← 체크 표시     │     │
│  │  ├──┼──┼──┼──┼──┼──┼──┤                 │     │
│  │  │ 8│ 9│..│  │  │  │14│                 │     │
│  │  ├──┼──┼──┼──┼──┼──┼──┤                 │     │
│  │  │15│  │  │  │  │  │21│                 │     │
│  │  ├──┼──┼──┼──┼──┼──┼──┤                 │     │
│  │  │22│  │  │  │  │  │28│                 │     │
│  │  └──┴──┴──┴──┴──┴──┴──┘                 │     │
│  │  특정 칸에 보상 아이콘 표시 (Gold/아이템)   │     │

│                                                  │
│  [출석하기] 버튼                                   │
│  ├─ 당일 첫 출석 → 체크 표시 + 보상 수령             │
│  │   보상: Gold 또는 성장 아이템 (칸별 상이)         │
│  ├─ 이미 출석 → "오늘 출석 완료" 버튼 (비활성화)      │
│  └─ 28일 완료 → "이번 달 출석 완료" 버튼 (비활성화)   │
│                                                  │
│  규칙:                                            │
│  ├─ 하루 1회, 서버 시간 기준                        │
│  ├─ 누적 방식 (연속 아님)                           │
│  └─ 28일 고정 (윤달/윤년 무관)                      │
└──────────────────────────────────────────────────┘
```

## 4. 학습 플로우

### 4-1. 전체 학습 사이클

```
홈 → [학습 시작] → 학습 화면 → [종료] → 학습 결과 화면 → [확인] → 홈
```

**학습 화면**:
- 학습 목표 입력 다이얼로그 (선택) → 스톱워치 시작
- 5초마다 로컬 저장소 백업, 1분마다 서버 동기화
- 실시간으로 같은 태그 학습자 표시
- [목표 확인], [일시정지/재개], [종료] 액션
- 종료 시 목표 확인 다이얼로그 → [저장]

**학습 결과 화면**:
- 공부 시간, 학습 내용, 화분 성장 결과 (레벨업 애니메이션)
- 학습 완료 보상: 아이템 + 보너스박스 (시간 티어별 차등, 상세는 PRD 참조)
- [갤러리 저장], [커뮤니티 공유 토글]
- [확인] → 홈으로 복귀

### 4-2. 비정상 종료 → 복구 플로우

```
학습 중 앱 강제 종료 → 다음 실행 시 로컬 세션 감지 → 복구 다이얼로그
  ├─ [저장] → 이전 학습 기록 저장
  └─ [취소] → 세션 클리어 (홈 유지)
```

### 4-3. 학습 기록 공유 플로우

```
화분 상세 → 기록 선택 (다중 체크) → [공유] → 게시글 작성 화면 (공유 모드) → 등록 → 커뮤니티 목록
```

## 5. 커뮤니티 플로우

### 5-1. 게시글 탐색

**화면 구성**:
- 검색 바 (제목/본문 필터)
- 태그 필터: 전체 / 공유 / 태그별
- 게시글 카드 목록 (무한 스크롤)

**진입 가능 액션**:
- 카드 탭 → 게시글 상세 화면
- 새로고침 → 처음부터 재조회
- [글 작성 버튼] → 게시글 작성 화면

### 5-2. 게시글 작성/수정

**작성**: 커뮤니티 목록 → [글 작성 버튼] → 제목(≤50자), 태그, 본문(≤1,000자) 입력 → [등록] → 목록 복귀

**수정**: 게시글 상세 → [수정] (본인만) → 기존 내용 채워진 편집 화면 → [수정] → 상세 복귀

### 5-3. 게시글 상세 · 상호작용

**화면 구성**:
- 작성자 프로필 (닉네임, 이미지), 제목, 본문/학습 기록(공유 게시글), 태그, 작성 시간

**상호작용**:
- ❤️ 좋아요 (본인 글 불가) / 🔖 북마크 (본인 글 포함 가능)
- 댓글 목록: 입력(≤100자), 수정/삭제 (본인 댓글만)
- [수정] [삭제] (본인 글만)
- 새로고침 → 상세 재조회

### 5-4. 게시글 삭제

```
게시글 상세 → [삭제] (본인만) → 확인 다이얼로그 → 커뮤니티 목록으로 복귀
```

### 5-5. 활동 내역

```
커뮤니티 목록 → [활동 내역] → 활동 내역 화면
  ├─ 필터: 게시물 / 댓글 / 좋아요
  ├─ 활동 카드 탭 → 게시글 상세 (삭제된 게시글은 안내 표시)
```

## 6. 아이템 · 보상 · 상점 플로우

> 아이템 종류, 등급, 수급 경로, 보너스박스 확률, 상점 가격, 레벨업 소비 조건 등 상세는 **PRD 참조**

**주요 흐름**:
- **보너스박스 개봉**: 학습 결과 화면에서 수령 → [열기] → 확률 드롭 연출 → [다음 박스] / [완료]
- **상점 구매**: 상점 화면 → 보유 Gold 확인 → 아이템 선택 → 구매 확인 다이얼로그 → Gold 차감
- **레벨업 아이템 소비**: 누적 학습 시간 충족 시 필요 아이템 자동 차감 → 레벨업 (아이템 부족 시 대기 상태)

## 7. 리포트 플로우

**리포트 화면 구성**:
- **학습 달력**: 공부한 날짜에 표시, 날짜 선택 시 해당 일자 학습 기록 표시
- **일간 학습 통계**: 총/최대/최소/평균 공부 시간
- **월간 학습 통계**: 월간 학습 시간 그래프, 총/최대/최소/평균

---

## 8. 마이페이지 플로우

**화면 구성**:
- **프로필 영역**: 닉네임, 프로필 이미지, 총 공부 시간, [프로필 편집]
- **메뉴 목록**: 북마크 목록, 다크모드 토글, 로그아웃, 회원탈퇴

| 출발 화면 | → 도착 화면 | 트리거 |
|-----------|------------|--------|
| 스플래시 | 홈 | 자동 로그인 성공 |
| 스플래시 | 로그인 | 자동 로그인 실패 |
| 로그인 | 홈 | Google 로그인 (기존 유저) |
| 로그인 | 닉네임 설정 | Google 로그인 (신규 유저) |
| 닉네임 설정 | 홈 | 닉네임 설정 완료 |
| 홈 | 학습 화면 | "학습 시작" 탭 |
| 홈 | 화분 생성 | 화분변경 다이얼로그 → "+새로운 화분 만들기" |
| 홈 | 나의 정원 | 하단바 탭 |
| 홈 | 화분 상세 | 대표 화분 상세 |
| 나의 정원 | 화분 상세 | 화분 카드 탭 |
| 화분 상세 | 학습 화면 | "학습 시작" |
| 화분 상세 | 게시글 작성 | 학습 기록 공유 |
| 학습 화면 | 학습 결과 | 학습 종료 + 저장 |
| 학습 결과 | 홈 | "확인" 탭 |
| 학습 결과 | 게시글 작성 | 커뮤니티 공유 토글 |
| 커뮤니티 목록 | 게시글 상세 | 게시글 카드 탭 |
| 커뮤니티 목록 | 게시글 작성 | [글 작성 버튼] |
| 게시글 상세 | 게시글 작성 | "수정" (본인 글) |
| 게시글 상세 | 커뮤니티 목록 | "삭제" 완료 |
| 마이페이지 | 로그인 | 로그아웃 / 회원탈퇴 |
| 커뮤니티 목록 | 활동 내역 | "활동 내역" |
| 활동 내역 | 게시글 상세 | 활동 카드 탭 |
| 나의 정원 | 화분 생성 | 우측 상단 + 버튼 |
| 화분 생성 | 홈 | 화분 생성 완료 |
| 아무 화면 | 로그인 | 세션 만료 |

### 9-3. 다이얼로그 목록

| 다이얼로그 | 표시 화면 | 트리거 |
|-----------|----------|--------|
